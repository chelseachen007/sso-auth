SSO Auth Demo

Web Components SSO 认证组件演示

登录组件 <sso-login>

支持用户名/邮箱登录和 OAuth 第三方登录（GitHub、Google）。 

<sso-provider base-url="http://localhost:3002">
  <sso-login
    show-oauth
    oauth-providers='["github", "google"]'
    register-link="/register"
  ></sso-login>
</sso-provider>

<script>
document.addEventListener('sso-login-success', (e) => {
  console.log('登录成功', e.detail);
});
</script>

注册组件 <sso-register>

用户注册表单，支持用户名、邮箱、密码注册。 

<sso-provider base-url="http://localhost:3002">
  <sso-register login-link="/login">
  </sso-register>
</sso-provider>

用户资料组件 <sso-profile>

查看和编辑用户资料信息。

请先登录后查看用户资料

会话管理组件 <sso-sessions>

管理用户登录会话，支持查看、撤销会话。

请先登录后查看会话管理

嵌入式 SDK

支持弹窗式和 iframe 嵌入式登录。

弹窗登录

const auth = new SsoEmbedded({
  baseUrl: 'http://localhost:3002',
  ssoUrl: 'http://localhost:3002'
});

auth.openPopupLogin({
  onSuccess: (data) => {
    console.log('登录成功', data);
  }
});

iframe 嵌入

auth.embedLogin('#container', {
  onSuccess: (data) => {
    console.log('登录成功', data);
  }
});

使用方式

1. 安装

npm install @sso-auth/components @sso-auth/core

2. 在 HTML 中直接使用（CDN）

<script type="module" src="https://unpkg.com/@sso-auth/components/dist/define.js"></script>

<sso-provider base-url="https://sso.example.com">
  <sso-login></sso-login>
</sso-provider>

3. 在 React 中使用

import '@sso-auth/components/dist/define.js';

function App() {
  return (
    <sso-provider base-url="https://sso.example.com">
      <sso-login onSsoLoginSuccess={handleLogin}></sso-login>
    </sso-provider>
  );
}

4. 在 Vue 中使用

import '@sso-auth/components/dist/define.js';

<template>
  <sso-provider base-url="https://sso.example.com">
    <sso-login @sso-login-success="handleLogin"></sso-login>
  </sso-provider>
</template>

5. 使用 Core SDK

import { SsoClient } from '@sso-auth/core';

const client = new SsoClient({
  baseUrl: 'https://sso.example.com'
});

// 登录
const result = await client.login({
  email: 'user@example.com',
  password: 'password'
});

// 获取用户信息
const user = await client.fetchUser();

// 登出
await client.logout();
